# Climate-Data-Predictive-Modeling
This project analyzes a 5-year meteorological dataset to identify weather patterns and predict future precipitation. Using Python, the script performs data cleaning and missing-value interpolation with pandas, generates statistical summaries and multi-line visualizations to track seasonal trends, and builds a polynomial regression model using NumPy to forecast precipitation based on historical temperature data. Model accuracy is evaluated using Mean Squared Error (MSE) and R-squared metrics.

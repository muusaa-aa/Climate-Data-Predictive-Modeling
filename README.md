# Climate Data Predictive Modeling 🌤️📊

## Overview
The Climate Data Predictive Modeling project is a data science and machine learning application developed to analyze meteorological trends and forecast precipitation levels across three distinct cities using a 5-year historical dataset. Built using Python, the system cleans raw time-series weather records, executes detailed exploratory data analysis through custom multi-city visualizations, and implements a Polynomial Regression model to accurately predict future rainfall patterns.

## Features
* **Multi-Year Data Cleaning:** Preprocesses, filters, and standardizes raw 5-year meteorological time-series records across multiple geographical locations using `pandas` and `NumPy`.
* **Exploratory Data Visualization:** Generates comparative multi-line charts and distribution histograms using `Matplotlib` to highlight cross-city temperature fluctuations and rainfall frequency.
* **Non-Linear Predictive Modeling:** Trains and evaluates a Polynomial Regression model to capture complex seasonal climate shifts and forecast future precipitation levels.
* **Trend & Pattern Extraction:** Analyzes seasonal variability to extract actionable environmental insights that guide feature selection and improve model predictive performance.
